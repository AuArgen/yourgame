Бул проекттин пайдубалы — маалыматтардын тактыгы жана тарыхтын сакталышы. Сиздин талаптардын негизинде PostgreSQL үчүн маалымат базасынын техникалык тапшырмасын (ТТ) иштеп чыктым.

Биз бул жерде "Relational Data Integrity" (маалыматтардын байланыш бүтүндүгү) принцибин колдонобуз.

«Своя Игра» Платформасынын Маалымат Базасынын ТТ (DB Schema)
1. Колдонуучулар жана Коопсуздук (Users & Security)
   Бул бөлүм каттоо, кирүү жана DDoS'тон коргоо үчүн кызмат кылат.

Таблица: users (Платформанын ээлери/Алып баруучулар)

id (UUID/Serial, PK): Колдонуучунун уникалдуу IDси.

username (Varchar 50, Unique): Колдонуучунун аты.

email (Varchar 100, Unique): Электрондук почта.

password_hash (Text): Паролдун шифрленген түрү (BCRYPT/Argon2).

created_at (Timestamp): Катталган убактысы.

Таблица: auth_attempts (DDoS жана Brute-force коргоо)

id (BigSerial, PK).

ip_address (INET): Колдонуучунун IP дареги.

attempt_type (Varchar): 'login' же 'register'.

attempt_time (Timestamp): Аракет болгон убакыт.

status (Boolean): Ийгиликтүү же ийгиликсиз.

2. Оюндун Конструктору (Game Templates)
   Бул жерде колдонуучу түзгөн оюндун пакеттери (суроолор, категориялар) сакталат.

Таблица: games (Оюндун жалпы маалыматы)

id (UUID, PK).

creator_id (FK -> users.id, Restrict Delete): Ким түздү. Эгер колдонуучунун түзгөн оюндары бар болсо, ал колдонуучуну өчүрүүгө болбойт.

title (Varchar 255): Оюндун аты (мис: "Тарых билермандары").

description (Text): Оюн жөнүндө кыскача маалымат.

created_at (Timestamp).

Таблица: categories (Оюндагы бөлүмдөр)

id (UUID, PK).

game_id (FK -> games.id, Cascade Delete).

name (Varchar 100): Категориянын аты (мис: "Кыргызстандын географиясы").

display_order (Int): Категориялардын тизмектеги орду (1, 2, 3...).

Таблица: questions (Суроолордун базасы)

id (UUID, PK).

category_id (FK -> categories.id, Cascade Delete).

points (Int): Суроонун баасы (100, 200, 300...).

question_text (Text): Суроо өзү.

answer_text (Text): Туура жооп.

is_cat_in_bag (Boolean, Default False): "Мышык чыгуу" суроосу экендигин билдирет.

time_limit (Int, Default 30): Жооп берүүгө берилген убакыт (секунд менен).

media_type (Enum): 'text', 'image', 'youtube_video'.

media_url (Text, Nullable): Сүрөттүн жолу же YouTube шилтемеси.

3. Оюндун Сессиясы жана Оюнчулар (Live Session)
   Оюн башталганда түзүлүүчү маалыматтар.

Таблица: game_sessions (Учурдагы активдүү оюн)

id (UUID, PK).

game_id (FK -> games.id, Restrict Delete): Кайсы пакет колдонулуп жатат. Эгер бул пакет менен мурда ойнолгон сессиялар болсо, пакетти (шаблонду) өчүрүүгө болбойт. Бул тарыхты (History) сактоо үчүн маанилүү.

host_id (FK -> users.id): Оюнду ким башкарып жатат (авторизацияланган ээси).

status (Enum): 'waiting' (күтүү), 'active' (оюн жүрүп жатат), 'finished' (бүттү).

started_at (Timestamp).

finished_at (Timestamp).

Таблица: participants (Оюндун катышуучулары)
   Оюнду баштаарда алып баруучу (авторизацияланган адам) тарабынан гана кошулат.

id (UUID, PK).

session_id (FK -> game_sessions.id).

player_name (Varchar 50): Оюнчунун аты.

current_score (Int, Default 0): Учурдагы упайы (минус болушу мүмкүн).

4. Оюндун Тарыхы (Logging & History)
   Бул таблица ар бир кыймылды ("Ким, качан, эмне кылды?") сактап калат.

Таблица: game_logs (Эң маанилүү тарых таблицасы)

id (BigSerial, PK).

session_id (FK -> game_sessions.id, Cascade Delete).

question_id (FK -> questions.id, Nullable): Кайсы суроо ачылды же жооп берилди.

participant_id (FK -> participants.id, Nullable): Ким аракет кылды.

action (Enum):

question_selected (суроо тандалды)

timer_expired (убакыт бүттү, эч ким жооп берген жок)

cat_transferred (мышык башка оюнчуга өткөрүлдү)

answer_given (жооп берилди)

score_added (упай кошулду)

score_deducted (упай алынды)

manual_adjustment (алып баруучу упайды кол менен өзгөрттү)

value_changed (Int): Канча упайга өзгөрдү (+200, -200).

recorded_at (Timestamp): Окуя болгон так убакыт.

5. Индекстер (Оптимизация үчүн)
   IDX_auth_attempts_ip: IP боюнча издөөнү тездетүү үчүн.

IDX_game_logs_session_time: Бир сессиянын тарыхын хронологиялык тартипте (session_id, recorded_at) тез чыгаруу үчүн.

IDX_questions_category: Суроолорду категория боюнча тез жүктөө үчүн.

6. Маалыматтардын бүтүндүгүн коргоо (Safe Deletion Policy)
   Проектте маалыматтарды кокусунан же туура эмес өчүрүп албоо үчүн төмөнкү эрежелер колдонулат:

Иерархиялык өчүрүү (Cascade): Эгер оюндун шаблону (Game Template) эч качан ойноло элек болсо (сессиялары жок болсо), аны өчүргөндө ага таандык категориялар жана суроолор кошо өчүрүлөт.

Өчүрүүгө тыюу салуу (Restrict): Эгер оюн шаблону менен жок дегенде бир жолу оюн өткөрүлгөн болсо (game_sessions таблицасында жазуу болсо), бул шаблонду базадан өчүрүүгө тыюу салынат. Бул мурунку оюндардын тарыхын жана статистикасын сактап калуу үчүн керек.

Колдонуучуну коргоо: Эгер колдонуучунун базада түзгөн оюндары же өткөргөн сессиялары бар болсо, ал колдонуучуну базадан өчүрүүгө система жол бербейт.

Бул базанын артыкчылыгы:
Маалымат жоголбойт: Оюн учурунда баракча жаңыланса (F5), сайттан чыгып кетсе же свет өчүп калса, `game_logs` аркылуу упайларды жана кайсы суроолор ачылганын калыбына келтирүү (restore state) оңой.

Тактык: Ар бир упайдын жана аракеттин тарыхы бар. "Эмне үчүн бул оюнчунун упайы кемиди?" десе, логдордон хронологияны көрүүгө болот.

Тарыхты кайра көрүү: Бир оюндун шаблонун 10 жолу ойнотсоңуз, базада 10 башка `game_sessions` сакталат. Ар бир сессиянын өз тарыхын өзүнчө көрө аласыз.

Ийкемдүүлүк: Бир эле оюнду (пакетти) бир нече жолу ар башка компаниялар менен ойносо болот (сессиялар бөлөк сакталат).
