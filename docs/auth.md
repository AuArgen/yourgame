Авторизация жана Каттоо Системасынын Техникалык Тапшырмасы
1. Функционалдык талаптар
   Каттоо (Registration):

Колдонуучудан талап кылынган маалыматтар: Username, Email, Password, Confirm Password.

Валидация: Email уникалдуу болушу керек, пароль кеминде 8 белгиден туруп, тамга-сандарды камтышы шарт.

Кирүү (Login):

Email (же Username) жана Password аркылуу кирүү.

"Мени эстеп кал" (Remember Me) функциясы (Cookie аркылуу).

Чыгуу (Logout):

Сессияны толук тазалоо жана башкы бетке багыттоо.

2. Коопсуздук жана DDoS'тон коргоо (Security & Rate Limiting)
   Бул бөлүм проекттин туруктуулугун камсыз кылат:

Brute-force жана DDoS коргоо:

Бир IP даректен 1 мүнөт ичинде 5 жолу ката кирүү аракети болсо, система ал IP'ни 15 мүнөткө блоктошу керек.

Бул маалымат базадагы auth_attempts таблицасы аркылуу текшерилет.

Паролдорду сактоо:

Паролдорду базага эч качан ачык текст түрүндө сактабоо.

PHP'нин password_hash() функциясын (Argon2id же BCRYPT алгоритми менен) колдонуу.

SQL Инъекциядан коргоо:

PDO'нун Prepared Statements (даярдалган сурамдар) механизмин гана колдонуу.

CSRF коргоо:

Ар бир формага уникалдуу жашыруун токен (CSRF Token) кошуу. Бул башка сайттардан жасалган жасалма сурамдардан коргойт.

Сессия коопсуздугу:

session.cookie_httponly — JavaScript аркылуу сессияны уурдоого жол бербейт.

session.cookie_secure — HTTPS аркылуу гана иштөө.

3. Логикалык алгоритм (Flow)
   А. Кирүү алгоритми:
   Колдонуучу IP дареги боюнча auth_attempts таблицасынан текшерилет (Блокто эмеспи?).

Киргизилген Email боюнча базадан колдонуучу изделет.

Эгер табытса, password_verify() аркылуу пароль текшерилет.

Ийгиликтүү болсо: auth_attempts таблицасындагы ошол IP'ге таандык каталар тазаланат, сессия ачылат.

Ката болсо: auth_attempts таблицасына жаңы жазуу кошулат (IP, убакыт, статус=ката).

Б. Каттоо алгоритми:
Маалыматтардын бош эместиги жана форматтары текшерилет.

Email мурун колдонулганы текшерилет.

Пароль хэштелет.

Жаңы колдонуучу базага жазылат жана дароо сессия ачылат.

4. Интерфейс (Tailwind CSS менен)
   Дизайн: Минимализм, "Clean UI".

Элементтер:

Ортодо жайгашкан форма (Centered Card).

Ката болгондо кызыл түстөгү эскертүүлөр (Alerts).

Киргизүү талаалары (Inputs) фокуста болгондо Tailwind'тин ring-2 ring-blue-500 сыяктуу эффекттерин колдонуу.

"Жүктөлүп жатат" (Loading spinner) абалы баскычты басканда.

5. Техникалык ишке ашыруу (Stack Detail)
   PHP: $_SESSION механизмин колдонуу.

Database: PostgreSQL'деги users жана auth_attempts таблицалары.

Helper Class: Авторизация үчүн атайын Auth классын түзүү керек (Методдору: register(), login(), logout(), check(), isBlocked()).
