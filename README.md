# «Своя Игра» Платформасы

Бул проект — интерактивдүү «Своя Игра» (Jeopardy!) оюнун түзүү жана өткөрүү үчүн арналган веб-платформа. PHP 8.2, PostgreSQL жана Docker технологияларынын негизинде иштелип чыккан.

## 🚀 Проектти ишке киргизүү (Quick Start)

Проектти иштетүү үчүн компьютериңизде **Docker** жана **Docker Compose** орнотулган болушу керек.

### 1. Долбоорду көчүрүү жана даярдоо
Алгач `.env.example` файлынан `.env` файлын түзүп алыңыз:

```bash
cp .env.example .env
```

`.env` файлынын ичиндеги портторду жана базага кирүү маалыматтарын кааласаңыз өзгөртө аласыз. Демейки (default) маанилер:
- **Nginx Порт:** 9004 (http://localhost:9004)
- **DB Порт:** 5434

### 2. Docker контейнерлерин иштетүү
Проектти куруу жана иштетүү үчүн төмөнкү команданы бериңиз:

```bash
docker-compose up -d --build
```

Бул команда PHP-FPM, Nginx жана PostgreSQL контейнерлерин түзүп, ишке киргизет.

## 🗄️ Маалымат базасын инициализациялоо (Database Init)

Контейнерлер иштеп баштагандан кийин, маалымат базасынын таблицаларын түзүү керек. Ал үчүн төмөнкү команданы иштетиңиз:

```bash
docker exec -i yourgame_db psql -U user -d yourgame < src/database/init.sql
```

*Эскертүү: Эгер сиз `.env` файлында `PROJECT_NAME`, `DB_USER` же `DB_NAME` өзгөрткөн болсоңуз, командадагы аттарды да ошого жараша өзгөртүңүз.*

### Таблицалар түзүлгөнүн текшерүү:
```bash
docker exec -it yourgame_db psql -U user -d yourgame -c "\dt"
```
Сиз 8 таблицаны көрүшүңүз керек: `users`, `auth_attempts`, `games`, `categories`, `questions`, `game_sessions`, `participants`, `game_logs`.

## 📂 Проекттин түзүмү

- `docker/` — Docker конфигурациялары (PHP, Nginx).
- `public/` — Проекттин кирүү чекити (`index.php`) жана статикалык файлдар.
- `src/` — Backend логикасы (Repository, Auth, Database).
- `views/` — Интерфейс файлдары (Tailwind CSS колдонулат).
- `storage/` — Жүктөлгөн сүрөттөр сакталуучу папка.
- `docs/` — Техникалык документтер жана ишке ашыруу планы.

## 🛠️ Негизги функциялар

1. **Авторизация:** Каттоодон өтүү жана логин (Brute-force жана CSRF коргоосу менен).
2. **Dashboard:** Өзүңүздүн оюндарыңызды түзүү, өзгөртүү жана өчүрүү.
3. **Оюн Конструктору:** Категорияларды, суроолорду кошуу, упайларды жана таймерди белгилөө.
4. **Оюн Мотору:** Катышуучуларды кошуу, оюндун жүрүшүн башкаруу жана упайларды автоматтык эсептөө.
5. **Тарых:** Өткөрүлгөн оюндардын жыйынтыктарын жана логдорун көрүү.

## 📝 Колдонуу боюнча сунуштар

- Сүрөттөр жүктөөдө `storage/images` папкасына жазуу укугу (permissions) берилгенин текшериңиз. Docker чөйрөсүндө бул автоматтык түрдө чечилет.
- Оюн учурунда баракчаны жаңыласаңыз (F5), оюн токтоп калбайт. Система акыркы абалды `game_logs` таблицасынан кайра калыбына келтирет.
